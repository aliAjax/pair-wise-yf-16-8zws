# hxyfront-62004 滑雪板磨底放行账

把**雪板档案、磨板工单、砂带批次**接成一本放行账。刃角只作参考，开工前必须同时过厚度与砂带寿命校验。

## 业务规则

1. **开工联检**：按「磨前厚度 − 计划磨削量 ≥ 安全厚度」、砂带剩余寿命 ≥ 计划磨削量、放行快照有效（主管 + 绑定砂带 + 底板版本一致）、工位空闲逐项校验。任一不过即拒绝开工，写一条红色拒绝账，**工位、砂带持有、耗用一律不变**。
2. **放行失效**：底板新增损伤，或客户授权的厚度变化落档后，底板版本 +1；该雪板所有**未完工**工单（含加工中）的主管放行立即失效、退回测量；加工中工单释放砂带与工位（已耗用不退），已完工工单不受影响。
3. **砂带单边放行**：同一砂带同时刻只允许一侧持有。领取走 CAS 乐观锁（`version`），两台平板（PAD-01/PAD-02）并发开工时先到一侧入账、后到一侧在闸门处拒绝。
4. **离线测量回网**：离网测量先进本地队列，回网时**按雪板号合并**，同号多条取最晚一条有效数据，步骤以测量 ID 为幂等键。
5. **写入失败只重试未入账步骤**：每步 apply + 流水为一次原子持久化。写失败回滚到上一耐久快照并挂起交易（记录 cursor），重试从挂起步继续，已入账步骤按 `stepId` 跳过，绝不重放。

## 页面操作

- 工单卡片：主管放行（选绑砂带）→ 校验并开工（选砂带/工位）→ 按磨后实测厚度完工（按真实耗用扣砂带寿命）
- 雪板档案：上报底板损伤、客户授权改厚、在线测量
- 并发面板：一键模拟两台平板同时领同一砂带
- 离线面板：离网暂存测量 → 回网合并
- 故障面板：安排下一次写入失败 → 顶部横幅只重试未入账步骤；另有放行账流水与事务表

## 代码结构

```
src/domain/types.ts   领域模型 + 步骤/交易类型
src/domain/engine.ts  开工闸门 checkGate、各指令 planX、单步 applyStep（含 CAS）、流水渲染
src/domain/store.ts   串行锁、单步原子落账、挂起/重试、离线队列、localStorage 持久化
src/App.tsx           联检台界面
```

## 技术栈

React 19 + Vite + TypeScript，无后端，状态持久化在 localStorage。

## 本地运行

```bash
npm install
npm run dev      # http://localhost:62004
```

内置种子数据覆盖三种拦截演示：WO-302 磨后 1.30mm < 安全下限 1.4mm；BT-09 仅剩 0.05mm 寿命；WO-301/WO-302 可绑同一砂带演示双平板抢占。
